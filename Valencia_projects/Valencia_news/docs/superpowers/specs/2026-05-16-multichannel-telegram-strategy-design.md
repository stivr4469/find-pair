# Дизайн: Мультиканальная Telegram-сеть об Испании для русскоязычных

**Дата:** 2026-05-16  
**Проект:** Valencia News Bot → Сеть из 4 каналов + бот-гид  
**Цель:** Уникальный русскоязычный Telegram-канал с потенциалом роста до миллионов подписчиков

---

## 1. Контекст и отправная точка

Уже существует:
- Канал @Esp_Valencia_news — автоматический дайджест новостей 2 раза в день
- Афиша событий Валенсии каждые 5 часов
- AI-обработка через gemini-2.5-flash (OpenRouter)
- 21 источник новостей
- Python 3.12, SQLAlchemy, feedparser, BeautifulSoup4

Аудитория: русскоязычные (не «русские» — инклюзивно: украинцы, казахстанцы, белорусы и др.) эмигранты и туристы в Испании/Валенсии.

---

## 2. Стратегия: сеть из 4 каналов

Один мегаканал проигрывает сети тематических каналов:
- Каждый канал фокусный → алгоритм Telegram рекомендует его точнее
- Перекрёстное продвижение между каналами → органический рост
- Разные сегменты аудитории покрываются разными каналами

### Четыре канала

| Канал | Тема | Расписание |
|-------|------|-----------|
| 📰 Новости Валенсии | Текущие события, политика, городская жизнь | 08:00 + 19:00 |
| 🎭 Афиша Валенсии | События, выставки, концерты, культура | Каждые 5 часов |
| 🏖 Отдых в Испании | Маршруты, пляжи, города, парки | 10:00 + 18:00 |
| 🍽 Гастрономия Испании | Рестораны, блюда, рецепты, рынки | 11:00 + 20:00 |

### Что НЕ входит (отложено осознанно)
- 🏠 Жизнь в Испании (NIE, жильё, налоги) — требует экспертизы, неверный совет вреден
- 🎧 Аудиоконтент — исключён на данном этапе

## 3. AI-персоны для каждого канала

Контент полностью генерируется AI в голосе редактора-персонажа. Пользователь ничего не пишет вручную.

| Канал | Персона | Стиль |
|-------|---------|-------|
| 📰 Новости | Алексей — репортёр | Сухой, точный, без воды |
| 🎭 Афиша | Катя — культурный обозреватель | Живо, с настроением |
| 🏖 Туризм | Сергей — путешественник | Практично и вдохновляюще |
| 🍽 Гастрономия | Наташа — гастрокритик | Чувственно, с деталями |

Промпты хранятся в `ai/personas/` — отдельный файл на канал.

## 4. Источники данных

### Существующие (новости + афиша)
Valencia.es, El País Valencia, Las Provincias, Levante EMV, Valencia Plaza, IVAM, CCCC и др.

### Новые источники — Туризм
- El País Viajes
- National Geographic España
- Traveler.es (Condé Nast)
- Turismo Comunitat Valenciana (официальный)
- Lonely Planet España blog

### Новые источники — Гастрономия
- Directo al Paladar (есть RSS)
- El Comidista (El País)
- Gastronosfera.com
- Guía Repsol — новости и рейтинги

### База вечнозелёного контента

Туризм и гастрономия не зависят только от RSS — добавляется статичная база:

```
data/
  places_spain.json        # 300 достопримечательностей
  restaurants_valencia.json  # 100 ресторанов Валенсии
  dishes_spain.json          # 80 классических блюд
```

Структура записи:
```json
{
  "id": "sagunto_castle",
  "name": "Замок Сагунто",
  "location": "Сагунто, 35 км от Валенсии",
  "tags": ["история", "дети", "день поездки"],
  "last_published": null,
  "is_placeholder": false
}
```

`last_published` обновляется при публикации — одно место не выходит дважды за 60 дней.

**Микс контента:**
- Туризм: 50% RSS + 50% «место дня» из базы
- Гастрономия: 40% RSS + 30% «блюдо дня» + 30% «ресторан недели»

### Изменения в БД
Добавить колонку `channel` в таблицы `sources` и `articles`:
```sql
ALTER TABLE sources ADD COLUMN channel TEXT DEFAULT 'news';
ALTER TABLE articles ADD COLUMN channel TEXT DEFAULT 'news';
```

### Конфиг `.env`
```
CHANNEL_NEWS_CHAT_ID=@Esp_Valencia_news
CHANNEL_EVENTS_CHAT_ID=@Valencia_Afisha
```

## 6. @ValenciaGuideBot — интерактивный гид

Отдельный бот (отдельный токен). Не публикует посты — только отвечает на вопросы.

**Стек:** `python-telegram-bot` v20 (async) + OpenRouter gemini-2.5-flash

**Системный промпт:**
> Ты — гид по Валенсии и Испании для русскоязычных туристов. Отвечай конкретно: адреса, время работы, цены, маршруты. Стиль — дружелюбный местный житель. Никаких общих фраз — только конкретика.

**Хранение контекста:** последние 5 сообщений на пользователя (in-memory / Redis), без тяжёлой БД.

**Кнопки из каналов:**
- 🏖 Туризм → «🗺 Спланировать маршрут»
- 🍽 Гастрономия → «🍴 Найти ресторан»
- 🎭 Афиша → «📍 Как добраться»
- 📰 Новости → кнопки нет

## 7. Монетизация (Фаза 3 — после роста)

Заглушки встраиваются в архитектуру с первого дня. Когда канал вырастет — заглушка заменяется платным размещением без изменения кода.

**Пример в базе ресторанов:**
```json
{
  "id": "placeholder_001",
  "is_placeholder": true,
  "post_text": "🍽 Знаете лучший ресторан паэльи в Валенсии?\nЭто место пока свободно → @contact"
}
```

**Модель:** «Здесь могло быть ваше заведение» — ресторан видит уже существующее место в канале с аудиторией и платит за заполнение заглушки.

## 8. Стратегия роста

### Главный механизм — перекрёстное продвижение
Каждый канал раз в неделю публикует пост о других каналах сети.

### Виральные форматы

| Канал | Формат | Механика шеринга |
|-------|--------|-----------------|
| 🏖 Туризм | Маршруты с картой | «Перешли другу, кто едет в Испанию» |
| 🍽 Гастрономия | Рецепты + места | Сохраняют себе |
| 🎭 Афиша | События выходных | Зовут друзей |
| 📰 Новости | Горячие темы | Обсуждают, репостят |

### CTA в постах туризма и гастрономии
```
👥 Едешь в Испанию? Перешли другу
```

### SEO описаний каналов
Ключевые слова: «русскоязычные в Испании», «жизнь в Валенсии», «Испания для русскоязычных», «отдых в Испании», «афиша Валенсии»

> Важно: «русскоязычные» — не «русские». Инклюзивно для всей аудитории.

## 10. Риски и ограничения

| Риск | Митигация |
|------|-----------|
| AI генерирует неточную информацию о местах | Редакционная проверка базы данных перед запуском |
| Дублирование контента между каналами | Фильтр по `channel` в known_urls |
| Низкое качество RSS туристических источников | Микс RSS + база гарантирует минимум 1 пост в день |
| Тема «жизнь в Испании» — не включена | Осознанное решение: требует экспертизы |
