## СПЕЦИФИКА ПРОЕКТА

### Стек и ограничения

- **Нет сборщика** — `import`/`require` не работают. Всё через `<script>` теги и глобальные переменные `window.*`
- **Нет TypeScript** — только plain JS. Документировать сигнатуры через JSDoc если нужно
- **Нет тестов** — покрытие обеспечивается ручной проверкой в браузере через Playwright или `http.server`
- **Cache-busting** — при изменении любого `.js` файла обязательно bump `?v=N` в `index.html` модуля

### Версии файлов (актуальные)

### Паттерн двухуровневой навигации

Все модули кроме `find-pair` имеют два уровня:

```html
<div class="back-button-container">
    <a href="../" class="back-button">← Главная</a>
    <button id="btn-back-to-XXX" class="back-button" style="display:none"
            onclick="ModuleApp.showXxx()">← Список / Режимы</button>
</div>
```

В `app.js` каждого модуля есть `_syncBackBtn()` или аналогичная логика.

### Именование глобалов

```
UPPER_MODULE_DATA   ← данные (FORMULAS_DATA, PASADO_DATA, MEZCLA_DATA)
ModuleApp           ← контроллер (FormulasApp, PasadoApp, MezclaApp)
ModuleUI            ← рендеринг (FormulasUI, PasadoUI, MezclaUI)
moduleFunctionName  ← window-алиасы (formulaStartQuiz, pasadoHandleAnswer)
```

### Вёрстка и CSS

- Все общие стили — только в `css/unified-styles.css`
- Модульные стили — в `<style>` блоке внутри `index.html` модуля
- Inline стили в JS-генерируемом HTML — **избегать**, использовать CSS-классы
- **Никогда** не использовать `JSON.stringify` в onclick атрибутах — экранирование ломается
- После `innerHTML = ...` вызывать `lucide.createIcons()` если добавляются иконки

### Запрещённые паттерны

```js
// НЕЛЬЗЯ — сломается при спецсимволах
onclick="doSomething(${JSON.stringify(obj)})"

// НЕЛЬЗЯ — window.* глобалы будут затёрты при переходе
window.currentItem = item;  // потом в onclick читается уже другой item

// НЕЛЬЗЯ — после анимации инлайн-стиль переопределяет CSS
element.style.display = 'block';  // вместо этого — управлять классами

// НЕЛЬЗЯ — TTS не работает, возвращает сразу
speakSpanish(text);  // utils.js v=17 disabled — не рассчитывать на него
```

### Локальный сервер

```bash
python3 -m http.server 3001
# открывать http://localhost:3001/
```
