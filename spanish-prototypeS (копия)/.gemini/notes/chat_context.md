# Контекст чата: Разработка приложения для изучения испанского

Этот документ содержит ключевые моменты и решения, принятые в ходе разработки.

## Этап 1: Настройка проекта

- **Исходное состояние:** Проект на React + Vite уже существует в папке `example/`.
- **Действия:** Подтверждена корректность настройки.

## Этап 2: Пользовательский интерфейс

- **Задача:** Восстановить отображение карточек с формулами.
- **Действия:**
    - Восстановлены файлы `formulas.js` и `FormulaCard.jsx` из бэкапов.
    - `App.jsx` обновлен для корректной передачи данных в `FormulaMenu`.
    - В `FormulaCard.jsx` исправлена ошибка `ReferenceError: onClick is not defined`.

## Этап 3: Логика работы с формулами и упражнениями

- **Задача:** Реализовать последовательное отображение упражнений для выбранной формулы.
- **Действия:**
    - В `exercises.js` добавлены новые упражнения.
    - В `App.jsx` добавлена логика для отслеживания и смены текущего упражнения (`currentExerciseIndex`).
    - `Formula1.jsx` модифицирован для работы с одним упражнением (`currentExercise`) и функцией `onNextExercise`.
    - **Исправлены ошибки:**
        - "Rendered more hooks than during the previous render" в `Formula1.jsx`.
        - Удален дублирующийся код, вызывавший ошибку 500.
    - **Улучшения:**
        - Из упражнений удален текст "(Пример X)".
        - Скорректирована логика фильтрации упражнений.

## Этап 6: Игровые механики

- **Задача:** Реализовать перемещение слов между банком и полем для составления предложения.
- **Действия:**
    - **Двойной клик:** Реализована и исправлена логика перемещения слов по двойному клику.
    - **Одинарный клик:** По запросу, двойной клик был заменен на одинарный.
    - **Исправлена проблема с перехватом событий:** `dnd-kit` мешал работе `onClick`. Проблема решена путем настройки `activationConstraint` для `PointerSensor` в `Formula1.jsx`.
- **Статус:** Функция работает корректно.

## Организация служебных файлов

- **Задача:** Собрать все служебные файлы в одном месте.
- **Действия:**
    - Создана папка `.gemini`.
    - Все заметки, задачи и основной контекстный файл (`GEMINI.md`) перенесены в `.gemini`.
    - Старые папки удалены.
- **Результат:** Все служебные файлы теперь находятся в `.gemini`.
