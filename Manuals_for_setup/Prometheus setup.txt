Запустите этот образ локально:

docker run -d --name prometheus-container -e TZ=UTC -p 9090:9090 ubuntu/prometheus:2.49.1-22.04_stable

Получите доступ к своему экземпляру Prometheus по адресу http://localhost:9090.

Параметры

Параметр	                                               Описание
-e TZ=UTC	                                               Часовой пояс.
-p 9090:9090	                                               Разоблачить Прометея на localhost:9090.
-v /path/to/prometheus.yml:/etc/prometheus/prometheus.yml      Локальный файл конфигурации prometheus.yml.
-v /path/to/alerts.yml:/etc/prometheus/alerts.yml	       Файл конфигурации локальных оповещений alerts.yml.
